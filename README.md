# 瓦罗兰特地图工具

## 启动
双击“启动地图工具.cmd”，浏览器进入 http://127.0.0.1:8788 。需要 Node.js 22 或更新版本，项目不需要安装第三方依赖。保持服务窗口打开。不要直接打开dist/index.html来使用账号和同步功能，静态打开只能浏览原始地图。

## 游客与管理员
打开网页默认以游客浏览，无需注册或登录。右上角“管理员登录”，初始账号admin，密码admin。登录后进入“管理员后台”。后台包括地图校准与账号设置，后续功能可在此扩展。

在“账号设置”填写新账号、当前密码、新密码和确认密码后保存。修改后所有管理员会话退出，使用新账号重新登录。若只改账号，新密码填写希望保留的密码。密码采用随机盐和scrypt哈希保存，登录会话使用HttpOnly Cookie，8小时失效，服务重启后需要重新登录。

## 校准地图
进入地图编辑，拖拽名称或圆点调整其对应位置（文字会自动避让，圆点代表实际坐标），点击“保存本地图”。支持放大地图后校准。游客每3秒读取同一服务保存的位置。未保存修改不会同步，可以“撤销本地图修改”。各地图草稿在本次打开页面期间保留，关闭页面前需逐张保存。

商街、古城、渔市缺少原始坐标参数：先点击点位列表中的名称，再点击地图放置；之后可以拖拽微调和保存。已由管理员校准的点位以绿色圆点显示。未校准的原始资料仍可能与当前游戏底图有差异。

多管理员同时编辑采用版本冲突保护，保存冲突时保留草稿并提示；请同步资料、撤销冲突地图草稿后重新调整，避免覆盖他人校准。

## 文件与数据
- dist/index.html：页面样式和结构
- dist/app.js：游客、后台与拖拽交互
- dist/data.js、dist/assets/：原始地图与本地图片
- server.cjs：账号认证、权限、位置保存与静态服务
- storage/state.json：首次启动自动生成，保存账号哈希和已校准位置；请备份此文件。不要删除该文件，否则账号和校准资料会重置。

同步范围是同一服务的所有浏览器。默认服务仅本机访问；复制项目后运行的两个独立服务不共享数据。本次开发预览8787端口与桌面正式启动8788端口为独立副本，请后续统一使用桌面入口。运行环境可通过HOST、PORT、ATLAS_DATA_DIR配置地址、端口及数据目录。
